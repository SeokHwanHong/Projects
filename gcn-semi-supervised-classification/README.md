# GCN 반지도 노드 분류

Kipf·Welling의 GCN 논문을 리뷰하고, 전파 규칙을 PyTorch로 구현해 GEMSEC Facebook 데이터에 적용한 개인 프로젝트입니다. **논문의 수식을 희소 행렬 연산·구조 특징·마스크 기반 학습으로 연결한 경험**을 정리합니다.

[프로젝트 해석과 회고](https://seokhwanhong.github.io/projects/gcn-semi-supervised-classification/)

## 목적과 수행 범위

GCN 논문의 전파 규칙을 이해하고 실제 그래프에 적용하는 것을 목표로 시작했습니다. GCN은 노드 특징과 연결 구조를 함께 사용하고 일부 노드의 라벨로 학습할 수 있어, 연결 데이터의 노드 분류에 적용했습니다.

본인 수행 범위는 구조 특징 구성, 정규화 인접행렬과 2층 GCN 구현, 학습·검증 및 출력 시각화입니다.

### 구조 특징과 학습 방식

입력 특징은 `degree`와 `adj_norm × degree`입니다. 첫 값은 입력 간선의 첫 번째 노드 열에서 집계한 차수이며, 두 번째 값은 self-loop를 포함한 정규화 행렬로 집계한 차수 값입니다. 두 값으로 노드의 연결 수와 주변 연결 구조를 표현했습니다.

두 값을 `Linear(2, 128)`로 투영합니다. 투영 가중치는 초기화 후 고정하고 GCN 가중치를 학습했습니다.

전체 그래프의 연결과 특징을 forward에 사용하되 손실은 학습 mask에서만 계산합니다. Adam의 학습률은 0.001, weight decay는 5e-4이며 소스는 300 epoch를 지정합니다.

## 결과의 한계와 후속 비교

기준 모델과 비교하지 않아 **GCN의 추가 집계가 같은 특징을 사용하는 단순 모델보다 도움이 되는지 판단하기 어렵습니다.** 전체 정확도만으로 어느 카테고리에서 예측이 어려운지도 충분히 설명하지 못했습니다.

후속 비교가 필요해지면 데이터·분할을 먼저 확인한 뒤, 같은 특징 행렬과 분할에서 간단한 MLP와 GCN을 비교할 수 있습니다. Accuracy·Macro-F1과 클래스별 재현율을 살펴보는 계획입니다. 입력 특징에도 이웃 정보가 포함되므로 이 비교는 그래프 정보 전체가 아닌 **GCN의 추가 집계 효과**를 살펴봅니다. 아직 수행하지 않았습니다.

## 데이터와 실행 범위

데이터·가중치·학습 이력 CSV는 이 디렉터리에 포함하지 않습니다. 노트북은 로컬 절대 경로를 참조하므로 `data/`에 파일을 두는 것만으로 실행되지 않습니다. 각 CSV·가중치·로그 경로를 실제 위치에 맞춰야 합니다.

현재 노트북의 import 기준 패키지는 PyTorch, NumPy, pandas, matplotlib, scikit-learn입니다. Python·CUDA·패키지 버전은 고정된 재현 환경으로 제공하지 않습니다.

전체 연결을 공유하는 transductive 설정에서 얻은 과거 검증 로그를 제시했습니다. 학습 정확도는 dropout이 적용된 갱신 전 출력, 검증 정확도는 가중치 갱신 후 eval 모드 출력으로 계산합니다. 두 정확도의 차이를 그대로 과적합 여부의 근거로 삼지 않습니다. 테스트 mask는 존재하지만 첨부·공개 노트북에서 테스트 정확도 계산은 확인되지 않습니다.

- **t-SNE:** 라벨 번호와 범례 이름 순서가 다릅니다. 현재 소스는 `epoch_180` 체크포인트의 최종 log-softmax 출력을 사용합니다. 기존 그림을 특정 카테고리의 분리나 분류 성능 증거로 사용하지 않습니다. 여러 epoch 그림의 동일 표본·특징 조건도 미확인입니다.
- **추론 입력 복원:** 투영·특징·mask를 다시 생성합니다. 체크포인트 저장 코드는 GCN·optimizer 상태 등을 저장하지만 투영과 분할은 포함하지 않습니다. 동일 시드만으로 학습 때와 입력이 같다고 확정하지 않습니다.
