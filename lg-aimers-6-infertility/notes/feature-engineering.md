# 파생변수 기록 — 코드로 확인한 후보와 귀속의 한계

개인 역할은 **모델 평가 지표와 feature importance를 참고한 파생변수 탐색**이다(본인 설명). 아래는 노트북에 존재하는 코드의 목록이며 홍석환이 각 변수를 직접 작성했다는 증거는 아니다. 특히 과거 이력·원인/관측·수치/범주 조합은 담당 후보로 논의했으며 변수별 귀속은 확인 필요다. “설계 의도”는 현재 산식에서 해석한 가설이며 당시 문헌 활용·채택 경로를 복원한 진술이 아니다.

## 구현 경로와 자료형

[원본 코드 발췌](../src/feature-exploration-original.py)의 셀 번호는 markdown 포함 1부터 센 물리적 위치이며 실행 번호와 다르다. 셀6→7, 8→9, 10→11, 12→13, 14→15에서 각 함수를 정의하고 train/test 양쪽에 적용한다. 셀6은 지정 배아 관련 7열을 0 대치한다. 비율의 epsilon은 1e-6이다. 아래 자료형은 코드상 변환/추정이며 실제 dtype를 새 실행으로 확인하지 않았다. 셀17 인코딩 이후 및 셀33 float 변환 이후의 모델별 입력을 구별해야 한다.

## 중요도 해석과 후속 확인

CatBoost는 모델 feature_importances_의 fold 평균, LightGBM은 feature_importances_의 fold 평균(현재 소스 기본 split 중요도; 실행 버전 미확인), AutoGluon은 train_data를 전달한 permutation importance다. 서로 척도와 평가 데이터가 달라 수치를 직접 비교하지 않는다. 순위가 높아도 추가 전후 AUC 개선이나 임상 인과를 입증하지 않는다. 서로 중복/상관된 피처의 중요도도 나뉠 수 있다.

우선 변수별 담당 범위를 본인 설명·당시 파일/메시지로 확인한다. 다음으로 원본 데이터에서 0/결측 분모·극단값·중복 수량·변수 발생 시점을 확인한다. 필요할 때만 별도 버전에서 동일 분할의 제거/추가 실험을 설계한다. 이번에는 계산·학습하지 않았다.
