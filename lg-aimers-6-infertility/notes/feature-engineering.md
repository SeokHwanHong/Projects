# 전처리·피처 설계 기록

근거는 팀 발표자료 5~7쪽, 전처리 중간 CSV와 텍스트 실험 메모다. 메모의 설계안과 실제 CSV 열을 구분한다.

| 설계 | 확인 자료 | 확인 범위 |
| --- | --- | --- |
| 특정 시술 유형 공백 제거, LabelEncoding, 테스트 전용 범주 Unknown | 발표 5쪽 | 코드 및 모델별 결측 전달 형식 미보존 |
| 배아 변수 공통 결측을 시술 유형과 연결 | 발표 4쪽, 원본 CSV 재집계 | DI 6,291행에서 배아 관련 5개 변수 모두 결측, IVF 250,060행에서 모두 관측 |
| 수치·범주 동시 표현 | 발표 6쪽, 중간 CSV | 이식된 배아 수, 미세주입 배아 이식 수, 배아 이식 경과일, 저장된 배아 수의 _num / _cate |
| 난자·배아 활용률, 저장률, 수량 차이 | 중간 CSV | ICSI 효율, 신선 난자 활용률, 배아 저장 비율, 생성-저장 배아 차이 등 열 존재 |
| 불임 원인 합계 | 중간 CSV, 메모 | 합계 열 존재; 세부 원인 합산 산식도 메모에 존재 |
| 이전 IVF·DI 횟수 합, 신규 시술 여부 | 메모 | 별도 실험 설계안이며 최종 채택 미확인 |
| 출처와 기증자 나이 조합, 이전 성공/시술 비율 | 메모 | 산식 기록; 데이터프레임 이름 혼용 및 0 분모 처리 미명시 |

`6회 이상` 범주는 126,244행 메모에서 매우 드물어 재범주화를 검토했다. 원본 전체 256,351행의 빈도와 혼동하지 않는다. 최종 피처 목록, 제거 실험 및 fold별 점수가 없어 개별 피처의 성능 향상을 확정할 수 없다.
